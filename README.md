## Getting Started

## Fungua Visual Studio Code from Search

1. Drag folder kwenye visual studio code

# or

1. Click Open Folder then on Desktop(j), then select KB MMBAGA


2. Kwenye Top Bar utaona Terminal click then select new terminal
- Itafunguka another window kwa chini ikifanana na hii: j@Js-MacBook mmbaga %

- Isipokua hivyo basi run au andika: cd mmbaga 


2. Baada ya apo utaandika au kucopy na kupaste kwenye terminal : 

- npm run dev

- - Kama ilivyo apo kwenye terminal


3. Utaenda kwenye browser na utaandika au copy na ukapaste kwenye browser hivi:
- http://localhost:3000

- - Au click iyo link apo utafunguka kwenye browser.



NB: Hizi steps ni kwa local Development na sio kwa kuwa hosted online
